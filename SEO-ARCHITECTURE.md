# SEO architecture

Preserve category and product URLs, the taxonomy hierarchy, pagination and canonical URLs. Keep one meaningful primary heading per page, contextual links from commercial pillar pages into relevant categories and natural links between relevant products, categories and manufacturing content. Read links through existing WordPress helpers where the template already uses them.

Rank Math governs descriptions, canonicals, breadcrumbs and sitemaps when active. The private Core fallback conditionally supplies SEO output when the SEO integration is absent. Keep `wp_head()` and the WooCommerce hook pipeline. Check metadata and breadcrumbs once per page, including paginated archives, with Rank Math active. Preserve existing robots and sitemap rules for provisional pillars, empty archives and unapproved demo products. Changes to public URLs or indexing require owner review.
