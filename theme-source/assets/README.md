# Neutral asset slots

The public design export uses original, purpose-made placeholders for the desktop hero, mobile hero, fallback wordmark and fallback favicon. The filenames match the theme references so the styles and template paths can be reviewed directly. Existing photo placement and subject guidance are in the [design brief](../../DESIGN-REFERENCE.md).

Keep the approved private logo and launch media in the production theme during integration. WooCommerce and Elementor supply their attached images from the existing WordPress media library. Public redistribution of the production photos, marks, browser captures and third-party assets requires separate clearance.
